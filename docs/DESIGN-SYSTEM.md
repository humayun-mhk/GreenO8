# Greenova8 Landing Page — Design System

## Product position
Greenova8 is presented as a **climate-fintech investment marketplace**, not a crypto product. The landing page must make everyday investors feel that the product is understandable, controlled and trustworthy before they create an account.

## Visual direction
- **Brand roots:** keep the existing Greenova8 black/green wordmark character and renewable-energy cues.
- **Fintech layer:** controlled spacing, restrained cards, clear hierarchy, direct risk language and data-source disclosure.
- **Signature palette:** deep forest (`#082B20`), near-black (`#09150F`), energy lime (`#B9F46B`), verified green (`#22A763`), warm paper (`#FBFCF8`).
- **Typography:** system sans for product clarity, editorial serif italic used only for a few emphasis words.
- **Motion personality:** calm, precise and infrastructural. Motion should communicate state and flow, not decoration.

## UX rules
1. One dominant CTA above the fold: **Explore opportunities**.
2. Developer CTA remains visible but secondary.
3. No investor-facing financial figures unless returned by a configured backend endpoint.
4. Never imply a guaranteed return.
5. Explain the money/data chain before selling advanced features.
6. On mobile, simplify depth and layout instead of shrinking desktop composition.
7. Respect `prefers-reduced-motion`.

## Section grammar
1. Dark hero — proposition + 3D energy/data visual.
2. Asset band — supported renewable categories.
3. Marketplace surface — real API feed or honest not-configured state.
4. Four-step investor flow.
5. Dark scroll chapter — deposit → KYC → performance → payout.
6. Trust controls.
7. Project data pipeline.
8. Developer capital flow.
9. Investor support / escalation policy.
10. Impact integrity statement.
11. FAQ + risk language.
12. Final CTA and legal footer.
